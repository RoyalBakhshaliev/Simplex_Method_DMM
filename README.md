# 🪑 Simplex Method DMM (Decision-Making Models)

Консольное приложение на C++ для решения задачи линейного программирования (оптимизация производственного плана фабрики) классическим симплекс-методом.

## 📌 Описание проекта
Программа разработана в рамках курса «Модели принятия решений» (Decision-Making Models)[cite: 7]. Она определяет оптимальный объем выпуска четырех моделей стульев («стандарт», «комфорт», «престиж», «люкс») с учетом жестких ограничений по финансовым средствам, рабочему времени и запасам древесины[cite: 2].

## 🛠️ Стек технологий
* **Язык программирования:** C++ (ООП, структуры данных, файловый ввод-вывод)
* **Математический аппарат:** Двухфазный симплекс-метод, метод Жордана-Гаусса, расчет оценок и анализ чувствительности плана

## 📊 Результат оптимизации
* **Максимальная общая прибыль:** достигнута при оптимальном плане выпуска продукции.
* **Верификация:** Все расчеты проверены и сопоставлены с аналитическими расчетами в Excel («Поиск решения»).
